## 1. Диспетчер / высокоскоростной цикл — `FUN_08053af0` @ 0x08053af0

Это **не** switch по state, а **многочастотный кооперативный планировщик** (RTOS-like). Он крутит бесконечный цикл и на каждом «тике» вызывает массивы функций-указателей из таблиц в структуре `ctx->sched` (`*(int*)(iVar1+4)`), с разными делителями частоты. **[V]** 66398-66505.

```
do {
  FUN_0808368c(&local_8, 10);          // барьер ~10 мс → базовый тик = 100 Гц   [V] 66421
  // группа @off 0x08 (count @0x6c): КАЖДЫЙ тик  (~100 Гц)                        [V] 66422-66429
  // группа @off 0x30 (count @0x6e): каждые 2 тика (~50 Гц, флип iVar8)           [V] 66430-66444
  // группа @off 0x1c (count @0x6d): счётчик 1..9  → период ~10 тиков (~10 Гц)    [V] 66445-66459
  // группа @off 0x44 (count @0x6f): счётчик 3..0x13(19) → ~17 тиков              [V] 66460-66474
  // группа @off 0x50 (count @0x70): счётчик 4..0x18(24) → ~21 тик               [V] 66475-66489
  // группа @off 0x5c (count @0x71): счётчик 5..99 → ~95 тиков (~1 Гц)            [V] 66490-66504
} while(true);
```

- Базовый тик = **10 мс** (аргумент 10 в `FUN_0808368c`) → главный цикл **100 Гц**. **[V]** (адрес возвращаемого барьера — [I]).
- В эти таблицы **процесс-менеджер регистрирует `run`-функцию текущего состояния** и сервисы (движение, нож, датчики границы, батарея). Смена state через `FUN_0807976c` приводит к тому, что на следующих тиках отрабатывает `run` нового процесса. **[I]** (сам код регистрации таблиц отдельно не процитирован — **[U]** точный момент установки указателей).
- `FUN_08054274` @0x08054274 — **пример задачи в планировщике**: ждёт, пока привод встанет в idle (`vtable+0xc+0xc()==0`) и счётчик `+0x40≥+0x42`, затем `FUN_0807976c(5)` → **переход departure→cutting**. **[V]** 67074-67092.

## 2. Старт по «косить» — команда `0x300100de`

Кадр управления приходит в командный диспетчер; младшая часть id = **`0x100de`**. **[V]** 55577.

```c
if (iVar6 == 0x100de) {                                   // "set control command"
    iVar17 = FUN_08023f80(param_1, &DAT_0804709c);        // распарсить кадр
    if (iVar17 != 0) {
        iVar6 = FUN_08050448();
        (**(code**)(iVar6+0x14))(*(u8*)(iVar17+0x14));     // <-- контрол-БАЙТ команды
        ...  "set control command=%d"                      // [V] 55584
```
- Реальный **глагол** (start-mow / dock / stop / restart) — это **под-байт** `*(iVar17+0x14)`, передаваемый в `FUN_08050448()->vtable[0x14]`. Значение `0x20` = restart (видно в соседней ветке `0x101dc`, 55598). **[V]** для механики, **[U]** — полная таблица числовых значений «косить/на базу/стоп».
- Этот обработчик **выставляет отложенную команду**, которую в idle читает `process_wait`:
  `FUN_08028910` @0x08028910 возвращает `-1`, если есть pending-команда (`vtable+0x44()==-1`). **[V]** 55? / 28910-block.
- Далее в `process_wait` (`FUN_080270a8`, `FUN_080391e4`) по этой команде и проверкам ставится **state 4 (departure)**:
  `FUN_0807976c(4)` (36424, 36461, 36557) с логами `auto departure delay time is reached, goto departure`, `Robot on schedule, start work`. **[V]**.
- Строки, подтверждающие путь: `manual start command, change to departure` (0x08065f18), `robot in station, change to departure` (0x08066670), `start departure` (0x08067778). **[V]** строки; привязка к точной ветке — **[I]**.

## 3. Выезд с базы — state 4, `process_departure_smooth` (0x08032f20…0x08038xxx)

Нарратив (из строк 0x08031e..0x08038 + кода 48340-48455):

1. **Выезд назад из станции** — привод едет назад (`back`), меряя пройденную дистанцию `vtable+0xa0` (get-distance). Контроль: `leave station lifted again`, `leave station hitted`, `leave station back distance too short=%d and hitted`, `leave station hit overtime, back distance=%dmm`. **[V]** строки 1091-1104.
2. **Остановка + поворот на месте** — по достижении дистанции делается «cycle» (разворот): вызовы `(**(vtable+4)+0x60))(100,1,0x2d0)` = cycle(dist=100, dir=1, angle=0x2d0=720). **[V]** 48417/48439. Логи `departure cycle hit, change to random move`, `departure cycle finish, not in border, change to random move`. **[V]** 1100-1104.
3. **Проверка границы** — если после разворота робот не «в границе»: `departure cycle finish, no border, continue cycle right`. Если дождь: `departure rain, find border` / `departure rain and on border, dock`. **[V]** 1205-1208.
4. **Запуск ножа** — `leave station finish, start blade` (0x0803208c). **[V]**.
5. **Переход в кошение** — когда привод отработал и встал (см. `FUN_08054274`), `FUN_0807976c(5)`. **[V]** 67088.

> Departure — это большой под-автомат с `case`-переключателем шагов (видно `case 5/6` в 48450-48455). Имена шагов в `strings.txt` 4306-4315: `departure_step_follow_bd`, `departure_step_leave`, `departure_step_start_blade`, `cut_step_departure_station`. Точная нумерация под-шагов departure — **[I]** (полный автомат не разбирался пошагово).

## 4. Кошение — state 5, `process_cutting` (0x0802bcb4…0x080305e0)

Два уровня под-состояний:
- **main-step** `ctx_cut+0x138`: нормальная езда вперёд vs «random move to escape».
- **cycle sub-step** `ctx_cut+0x134` (ставится `FUN_0802f97c`, значения 0..6): нормаль(0)/движение вдоль границы «cycle»(1)/…/stall-recover(5)/ultrasonic-recover(6). **[V]** 41142-41155.

### 4a. Запуск ножа + безопасность + писк — `process_cutting` start-blade под-шаг (41180-41340)
- Проверки перед вращением ножа: **в станции?** → error; **lift (подъём)?** `vtable+0x34` → уйти в random-move; **updown==6** → `brake and goto error updown`; **hit==3** → random-move; **slope 4/2/5** → обработка. **[V]** 41199-41244.
- Раскрутка ножа: `vtable+0x10 -> +0x14/+0x18` (forward/backward), успех = `uVar3==2` → `start blade finish, turn to step random move`. **[V]** 41272-41276.
- **Реверс ножа для самоочистки**: счётчик `+0x148`, `%3==0` → main-step=6 (реверс), при `>0xe(14)` → ошибка `start blade stall`. **[V]** 41295-41314.
- **Писк/звук**: сервис звука `FUN_08077e10(3)` дёргается на каждом переходе (это, вероятно, «beep» перед/во время запуска ножа). Есть строки `cutting_without_beep` (0x080875d4), `speaker_en`/`config product speaker` (0x080775e0). **[I]** — что `FUN_08077e10(3)` = именно писк, не доказано побайтно (**[U]** точный код звука).

### 4b. Нормальная езда вперёд
- В нормали cut sub-step=0: привод едет вперёд (`front`), логи `unnormal front, set normal` / `blade normal, change to normal`. **[V]** 42301.
- Постоянно опрашиваются датчики: граница, hit (удар/бампер), lift, slope/tilt, ultrasonic, stall (клин колеса). **[V]** (везде в 42060-42300).

### 4c. РЕАКЦИЯ НА ГРАНИЦУ (in→out) — ядро `FUN_08030128` @0x08030128 (size 3618)
Это «border situation front» — что делать, когда датчики границы показывают выход за провод. **[V]** 42111-42298.

Ключевые опросы датчиков:
- `FUN_0805deec()==0` → **правый датчик вышел за границу** → `right border out, cycle left` (или `…back then cycle`). **[V]** 42111-42128.
- `FUN_0805df08()==0` → **левый вышел** → `left border out, cycle right`. **[V]** 42130-42147.
- `FUN_0805e140()==0` → **оба вышли** → `border all out, cycle left/right` (сторона выбирается `FUN_0802c424`). **[V]** 42149-42177.
- Узкий коридор: `narrow front border, cycle left/right` / `narrow but no saved action`. **[V]** 42180-42233.
- Нет сигнала совсем: `border all no signal, cycle left` (`vtable+0x88`). **[V]** 42274-42277.
- Возле станции: `front but block station, back cycle left, angle=135/45`. **[V]** строки 0x0802ceaf/cf18.

Примитивы, вызываемые отсюда:
- `FUN_0802c1c8(dir, 0x2d0)` — **выдать команду «cycle» (разворот вдоль/от границы)**, dir=1/2, angle-param 0x2d0=720. Внутри решает «сразу cycle» (`vtable+0x88`) или «сначала назад, потом cycle» по `FUN_0804e3e0()`. **[V]** 40698-…, 42113/42132/42209.
- `FUN_0802f97c(N)` — переставить cycle sub-step. **[V]**.
- `FUN_0804e3e0()` = байт-флаг `*(DAT+3)` — «надо ли сперва сдать назад» (in-border/на-проводе). **[V]** 62514.

### 4d. СЛУЧАЙНЫЙ УГОЛ РАЗВОРОТА
- **ГСЧ диапазона**: `FUN_0804f2c8(min,max)` = `rand % (max-min+1) + min`. **[V]** 63152:
  ```c
  iVar2 = (param_2 - param_1) + 1;
  return (iVar1 - iVar2*(iVar1/iVar2)) + param_1;   // == rand()%(max-min+1)+min
  ```
- Пример вызова: `FUN_0804f2c8(0x4b,0x87)` = **случайный угол 75°..135°**, затем `vtable+0x84 (0x104, 1, angle)`. **[V]** 42263-42264.
- **Случайное «лево/право»**: `FUN_0804f2ee()` = `rand&1 ? 1 : 2`. **[V]** 63?/`FUN_0804f2ee`.
- Строки-подтверждения: десятки `... cycle left/right, angle=%d`, `back cycle, angle=%d`, `cycle slipe times=%d, back cycle, angle=%d`. **[V]** strings 895-996.

### 4e. Угол → тики (для команд поворота) — `FUN_08020520` @0x08020520
```c
return (param_1 * 0x2b9) / uVar2;   // ticks = angle * 697 / speed_param(model)
```
- `0x2b9 = 697`. `uVar2` зависит от «модели»/скорости (поле `ctx+0x32/0x3a/0x42/0x4a/0x52` по индексу модели 0..4). **[V]** 31306-31335. Ошибка модели → лог `model error, angle could not change to tick`.

## 5. Примитивы движения и очередь `+0xe4`

Все примитивы кладут запись 0x24 байта в кольцо `*(ctx_move+4)+0xe4` и сдвигают указатель (`*ptr += 0x24`). Потребитель (сервис движения, зарегистрирован в планировщике §1) достаёт записи и крутит колёса. **[V]** 30877-31141.

| Примитив | Адрес | Что пишет в запись | Смысл |
|---|---|---|---|
| **forward** `FUN_0801fb04(spd,dist)` | 0x0801fb04 | `+4=2, +8=2, +0xc=2`, `+0x10/0x12=spd`, `+0x14/0x1c=dist` | ехать **вперёд** [V] 30884-30895 |
| **back** `FUN_0801fe8c(spd,dist)` | 0x0801fe8c | `+4=1, +8=1, +0xc=1` | ехать **назад** [V] 30970-30981 |
| **turn** `FUN_08020164(dir,spd,dist)` | 0x08020164 | dir=1→код 3, dir=2→код 4; иначе лог `turn dir param err` | **поворот на месте**, dir 1/2 [V] 31095-31140 |

- Более высокоуровневый «cycle» (разворот с дугой/углом) идёт через **vtable движения** `+0x60(dist,dir,angle)`, `+0x84(spd,dir,angle)`, `+0x88(dir,angle)` — используется в departure и в border-реакции. **[V]** 42092/42264/48417.
- Поля записи: `+4` тип(1=back/2=fwd/3=turnL/4=turnR), `+8` submode, `+0x10/0x12` param1 (скорость/угол), `+0x14/0x1c` param2 (дистанция). **[V]**.

## 6. Сервис ножа + звук

- **`service_blade` `FUN_08022938`** @0x08022938 — тикающий сервис ножа (в планировщике). Читает флаги `+0x25` (запрошенное направление), `+0x26` (force), `+0x27` (текущее направление), `+0x28`. Драйвит мотор ножа через `vtable+0x10 -> +0x14 (forward) / +0x18 (backward)`. Логи `force blade foreward, speed=%d` / `force blade backward, speed=%d`. Периодически **реверсирует** нож (переключает +0x27). **[V]** 32850-32920.
- Установка направления/тормоза ножа: `FUN_08022a80` (`set blade direction`), строки `set blade direction failed`, `set blade brake failed`, `blade service not running, cutting function could not excute`. **[V]** 32928-32963, strings 606-608, 0x08023917.
- **Звук**: `FUN_08077e10(n)` дёргается на переходах кошения; `set_product_enable_speaker` (0x080861df), `speaker_en`, `cutting_without_beep`. **[I]** что это именно писк безопасности; **[U]** точная генерация тона.

## 7. Граница / стыковка / зарядка (states 6/7/8)

- **find_bd (6)**: запускается из wait/при потере границы — строки `bdboard start search border`, `bdboard find border`, `lost bd, find border in, goto find bd`. Ставится `FUN_0807976c(6)` (44479, 44509). **[V]**.
- **docking (7)**: когда команда «на базу» и робот на проводе — `FUN_0807976c(7)` в `FUN_080391e4`, лог `dock command and on border, change ...`; `robot on border, goto docking`. Робот едет вдоль границы до станции. **[V]** 44503, strings 2023/3002/3018.
- **charging (8)**: `FUN_0807976c(8)` — `idle dock command and in station`, `Robot push into station, start charging`, `on schedule but battery voltage low, goto charging`. Управление током/этапами: `change to normal/trickle/temp-protect charging step`. **[V]** 44468, 36486, strings 705-707.
- **error (9)**: форсируется хелпером `FUN_08083d9c` (сам ставит `FUN_0807976c(9)`, 93238) — вызывается перед всеми `goto error`. Также `FUN_0802bce4(...)` (state 9) при фатальных ситуациях ножа/updown. **[V]** 93238, 40450.
- **power_off (10)**: `FUN_08025be0/FUN_08025c16`. **[V]** 35405-35429.

## 8. Защиты (lift / tilt / stall / hit / ultrasonic)

Опрашиваются каждый тик в cutting/departure; реакция — уход в «cycle/back cycle/random move»:
- **lift (подъём колёс)**: `find border but lift, reverse cycle right/left`, `back lift, cycle …, angle=%d`, `start blade but lift, turn to step random move to escape`. **[V]** strings.
- **tilt/slope (наклон)**: `back slope up, pitch=%d,roll=%d, cycle …`, `find border but slope, pitch=%d,roll=%d, reverse cycle …`. **[V]**.
- **stall (клин колеса)**: `front, wheel stall, back cycle …`, `wheel block time=%d, back cycle`, `torque back wheel stall, blade brake and escape`, `cycle stall recover`. **[V]** 42066-42079, strings 958/993.
- **hit (удар/бампер)**: `torque cycle hit, blade brake and escape`, `back hit, cycle …, angle=%d`, `front but block station …`. **[V]**.
- **ultrasonic (препятствие)**: `front ultrasonic, back cycle …`, `cycle ultrasonic recover`. **[V]** 42090-42102.
- Общий приём: при hit/stall с крутящим моментом — **тормоз ножа + «escape»** (`blade brake and escape`). **[V]**.

## 10. Где именно «цикл» и условия

- **Главный вечный цикл**: `FUN_08053af0` `do{…}while(true)` — тикает сервисы+`run` текущего state @100 Гц. **[V]** 66420-66505.
- **Цикл кошения** (граница→разворот→вперёд→граница) физически реализован тем, что `process_cutting_run` каждый тик снова вызывает `FUN_08030128`, и переходы cut sub-step (`FUN_0802f97c`) держат робота в state 5, пока не придёт команда/разряд/ошибка. Явного `for/while` «объезда периметра» нет — это событийный автомат. **[V/I]**.
- **Условия смены верхнего state**: только через `FUN_0807976c(N)` (см. карту вызовов §0/§7). Внутри cutting смена — через `+0x138`/`+0x134`, не через `0x10`.
