## Самое важное из этого прохода
- **[V] Мотор-PWM = TIMER2 CH3 (0x40000440)** — снимает гипотезу про advanced-таймер.
- **[V] IMU на I2C1 (PB10/PB11)**; но физический чип (ICM-42688@0x68 vs BNO055@0x28) — [U], оба вкомпилены.
- **[V] chip2: цифрового усиления коила НЕТ** — нормировка = авто-baseline при старте (avg5 → RAM 0x20000094, deflt 2048) + пороги (±2500/±5000). Под новые коилы крутить здесь.
- **[V] ⚠️ chip2 имеет аппаратный FLASH-CRC32 self-test (IEC60730, FUN_0801a5f0/FUN_080138a4)** — при провале плата виснет в halt-петле. В отличие от chip1, СВОЯ прошивка на chip2 без пересчёта CRC УРОНИТ плату.
- **[V] ГСЧ угла отскока = 75..135°** (FUN_0804f2c8(0x4b,0x87)); угол→тики = angle*697/speed.
- **[U] осталось:** реальная A4963-коммутация (кластер 0x0805f6xx без строк), физ. IMU-чип, RX-колбэк линка chip2.
