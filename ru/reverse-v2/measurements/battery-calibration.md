# Калибровка батареи — живые точки с заводской прошивки

Снято по SWD (non-halt) с работающей заводской прошивки chip1. Буфер DMA-скана ADC0
@`0x2000bb34` (адрес из DMA0 CH0 MADDR 0x40020014), RL=5, 16-бит на канал.
Порядок рангов (вероятный, ⚠️ rank→channel точно не сверен): 0=ch15/PC5 пак, 1=ch14/PC4 ток,
2=ch16 темп, 3=ch9/PB1 OCV, 4=ch17 Vref.

| Дата | Дисплей | rank0 (PC5 пак, raw) | pack_mV (=raw×5.4277) | rank1 ток | rank3 OCV | Прим. |
|---|---|---|---|---|---|---|
| 2026-07-06 | **100%** | 0x0E82 = **3714** | ~20 160 мВ (~20.16 В) | 0x0004≈0 | 0x0DA0=3488 | не на зарядке (ток≈0), state=3 |

## Вывод для нашей прошивки (firmware/mower-own/src/battery.c)
- `BATT_MV_FULL = 21000` слишком высок: при реальных 100% пак = ~20 160 мВ → наша формула дала бы ~86%.
- Откалибровать: 100% ≈ 20 200 мВ (по этой точке). Нужна ещё точка при низком заряде для наклона.
- ⚠️ rank→channel порядок не подтверждён на 100% — при след. заходе сверить (напр. по изменению rank1 на зарядке = ток растёт).
