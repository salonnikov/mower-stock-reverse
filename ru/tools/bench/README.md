# tools/bench — готовые скрипты стенд-теста привода (нулевая импровизация)

Запускаются **на малине** (там есть python3). Общаются с работающим `mower-openocd`
по telnet `:4444` (mdw/mww, без halt). Реализуют фазы из
`reverse-v2/reports/bench-test-plan.md`. На стенде — только запускать по порядку и
читать вердикт.

## Пред-полётный чеклист (СДЕЛАТЬ ДО запуска скриптов)
Железо:
- [ ] Ведущие колёса **вывешены** (крутятся свободно, ничего не заденут).
- [ ] Нож **физически отключён** (разъём мотора ножа).
- [ ] Питание стабильно (косилка на зарядке; малина от повербанка).
- [ ] SWD подключён к chip1.
- [ ] Рука рядом с обесточиванием.

Софт (на малине):
- [ ] `sudo systemctl status mower-openocd` — поднят.
- [ ] `sudo systemctl stop mower-webctl` — освободить единственного telnet-клиента.
- [ ] `cd` в каталог с этими скриптами.
- [ ] Связь: `python3 swd.py` → должно напечатать `СВЯЗЬ ОК` и текущее состояние.
      Если «Target not examined/halted» — в openocd-консоли `targets`; НЕ делать halt.

## Порядок запуска

| # | Команда | Что делает | Ждём / решение |
|---|---|---|---|
| связь | `python3 swd.py` | sanity-чтение state | `СВЯЗЬ ОК` |
| Ф0 | `python3 phase0_baseline.py` | читает state/TIMER2/слоты | **GO** = PWM-тракт активен; **NO-GO** = поднять сервис/сменить состояние |
| Ф1a | `python3 phase1_find_odom.py save` | снимок объектов колёс | «снимок №1 сохранён» |
| — | *провернуть оба колеса рукой ~10 об.* | (физически) | сказать «готово» |
| Ф1b | `python3 phase1_find_odom.py diff` | находит адрес тика | запиши АДРЕС тика L и R |
| Ф2 | `python3 phase2_watch_pwm.py` | стабилен ли CH3CV сам | СТАБИЛЕН → Ф3 прямо; ДЁРГАЕТСЯ → Ф3 `--loop` |
| Ф3 | `python3 phase3_drive.py L 500 <odomL>` | малый duty на левое | тики растут + колесо крутится = PWM вращает ✔ |
| стоп | `python3 estop.py` | обнулить все duty | в любой момент тревоги |

Ф3 при `ДЁРГАЕТСЯ`: `python3 phase3_drive.py L 500 <odomL> --loop`.
Наращивать duty (1000, 2000…) только если малый прошёл чисто. По одному колесу.

## Что каждый вердикт значит
- **Ф0 GO** → A4963 сконфигурен, TIMER2 CH3 активен → запись CH3CV осмысленна.
- **Ф3 тики растут + вращение** → **гипотеза «duty крутит» подтверждена ЖИВЬЁМ** (не из старых доков).
- **Ф3 тиков нет / колесо стоит** → duty сам не крутит → Фаза 4 плана (роль A4963 RUN/направления); скрипт для неё не готовим заранее — зависит от результата Ф3.

## Критерии немедленного СТОПа (жми estop.py + рви питание)
- Двигается НЕ то колесо / оба сразу.
- Посторонний звук/вибрация/нагрев/запах.
- Тики растут при команде 0.
- Косилка сама сменила состояние (ушла в departure/cutting) → поймали авто-старт: обесточить, вернуться, не входить в state 4/5/6.

## Границы (что скрипты НЕ делают)
- НЕ пишут во флеш, НЕ делают halt/reset/shutdown, НЕ трогают нож.
- Работают только с TIMER2 CHxCV и чтением RAM — всё откатывается снятием питания.
- Правый канал CH2CV (0x4000043c) — гипотеза (ⓗ); подтверди по Ф0 (какой CHxCV меняется при штатной езде), прежде чем гонять правое колесо.

## Адреса (сверка, из reverse-v2)
- state `0x200000bc` · movebase `*0x20000338` · lmdrv `*0x2000054c` · rmdrv `*0x2000057c`
- TIMER2: CTL0 `0x40000400` · CHCTL2 `0x40000420` · CAR `0x4000042c` · CNT `0x40000424`
- CH0..3CV `0x40000434/38/3c/40` — **ЛЕВОЕ колесо = CH3CV `0x40000440`**
