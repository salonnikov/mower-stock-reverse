# archive/injection-approach — ОТБРОШЕННЫЙ подход (инъекция в заводскую FSM)

Здесь собрано всё, что относится к попыткам управлять косилкой ЧЕРЕЗ инъекцию/hook в
заводскую прошивку (FSM). Подход отброшен 2026-07-04: FSM жёстко владеет приводом и валит в
error любое вмешательство (форс state → error; вызов драйверных функций из hook → мотор не
крутит + error + reboot). Заменено на СВОЮ standalone-прошивку `firmware/mower-own/`.

- `rc-payload/` — payload-инъектор (v1 счётчик, v2 RPC+RC) в свободный флеш + hook в hs-loop.
- `mower-executor/` — старый каркас параллельного аудита (неверные якоря), не использовался.
- `tools/` — генераторы/конфиги заливки инъекции (gen_flash_*, flash_*.cfg, pack_rc, build_proof).

Механика ДОКАЗАНА и переиспользуется (заливка+CRC+восстановление), но сам подход инъекции — тупик.
Актуальное: `firmware/mower-own/` (свой app), `tools/bench/app_crc.py` + `pack_own.py`.
